## 二、一句话简介

**用 AI 帮你留住家族故事、方言、菜谱和人生经验的家庭记忆档案馆。**

## 三、应用详细描述（应用市场简介）

> 建议 150–500 字，突出「情感刚需 + AI 技术」差异化。

**趁老人还能说，把家族故事永久保存下来。**

每一个家庭都有一部不为人知的历史：爷爷奶奶的爱情、父辈的奋斗、代代相传的菜谱、即将失传的方言。可当老人离去，这些记忆也随之消失。**家史馆**用 AI 帮你把它们留住。

**核心功能：**

- **🎙️ AI 智能采访**：根据老人年龄、籍贯、经历自动生成采访话题，像聊天一样自然引导，把口述故事变成文字记录。
- **🌳 家族知识图谱**：可视化家族关系网络，从对话中提取人物、地点、事件，支持自然语言查询。
- **🗺️ 记忆地图**：在地图上标注家族故事发生地，可视化迁徙路线。
- **💊 时光胶囊**：给未来的家人录一段话，设定日期解锁，端到端加密。
- **📜 传家宝**：保存家传菜谱、祖传手艺、家训格言。
- **☁️ 云端备份**：数据自动同步，换设备不丢，家人共享同一份家史。

**我们相信：记录，是最好的传承。**

## 七、构建 APK/AAB 步骤

本工程已用 Capacitor 8 完成 Android 壳配置（`client/android/`），构建需 Android 环境：

```bash
# 1. 安装 Android Studio（含 JDK 17 + Android SDK 36）
# 2. 同步并构建
cd client
npm run build                # 构建前端 dist
npx cap sync android          # 同步资源到 android
npx cap open android          # 用 Android Studio 打开
# 3. 在 Android Studio 中：Build → Generate Signed Bundle / APK
#    创建签名密钥（keystore），导出 release 版 APK/AAB
```

**签名密钥务必妥善保管**：上架后更新版本必须用同一个签名，丢失将无法升级。
